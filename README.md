Senja Lintas — Archipelago Rescue Air: a golden-hour seaplane flight game over a procedural archipelago. Fly five sorties — ring slalom, low survey pass, water rescue, cargo drop, and the flight home — with a real throttle/stall/fuel/hull flight model, chase and cockpit cameras with lit instruments, and a HUD showing altitude, airspeed and heading. Built with Three.js (vendored), no network requests, plays offline in desktop Chrome.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Controls: W/S throttle, arrow keys pitch & roll, A/D rudder, hold mouse to steer, C camera, Space action, R restart.
